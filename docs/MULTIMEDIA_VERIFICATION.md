## 本轮视频与网站验证

独立目录 `work/ui-output-verification`、模拟 Runtime 8792、界面 3002；真实服务密钥没有使用。视频图样由 FFmpeg 产生，音频为合成测试音，没有将其当作文化作品或真实配音。

新增 8 项自动测试：实际 MP4 / WAV 解码、多镜头及字幕／旁白／配乐合成、缺失或过长旁白拒绝、WorkBuddy 指定文件交接与取消、Runway 官方请求字段及重启恢复／不重复 POST、并行镜头采用及旧输入保护、网站结构／转义／资源校验与 ZIP、网站手动修改不再次调用模型、HTTP Range／CSP／备份哈希。原有 29 项继续通过。

页面实际操作：

1. 视频生成并采用两个 2 秒分镜；第一镜头及旁白通过 WorkBuddy 模拟交接，第二镜头通过外部视频接口模拟查询。全部预览并采用。
2. 自动合成、采用并下载 MP4 与 SRT。实际下载 MP4 为 H.264 / AAC、1280×720、4.000 秒；哈希与服务器文件一致。浏览器视频 `readyState=4`，用播放控件播放到 `currentTime=4`、`ended=true`，无解码错误；截图可见中文烧录字幕。声音为测试音，只证明存在音轨，不代表配音质量。
3. 网站生成、采用、手动编辑引言、重新打包、采用；再用自然语言修改并采用新结果。
4. 隔离预览中点击分类、搜索到空结果、用键盘清空搜索、切换页面、展开 FAQ，状态与可见内容一致。切换手机预览，实际 iframe 宽 389px；查看截图，工作台外层无横向溢出。本轮没有完整移动设备或无障碍审计。
