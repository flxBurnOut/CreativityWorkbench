# 全类型连续创作

2026-09-08 实施。延续 [提示词与 Harness](PROMPT_HARNESS.md) 的文化、系统与作品类型规则；本轮修复成果衔接，不降低创作约束。

## 共同操作

已保存成果作为下一步输入；继续完善、按要求修改与另作候选分别表达意图。生成任务保存输入清单和实际提示词，候选不会自动覆盖当前稿。文字与美术可采用并进入下一阶段；对象建议按项采用，更新保留对象 ID、原图与未选中项目。

`workflow.mjs` 同时供 Web 与 Runtime 解析输入、选择图片和记录依赖。图片只有作为实际附件时才标明附件；文字接口不声称看过图片。对象可指定内容小节、图片用途和已保存形象参考。原图编辑优先传入原文件；文化、美术、用途与修改要求随请求提交。

项目保存记录成果版本及来源。改变相关内容后，提醒具体受影响对象或成果；不再仅给出笼统的“上游变化”。手工编辑会形成当前版本，生成采用记录任务来源；旧项目没有证据的来源标为未知。恢复旧版本保留当时依赖，形成新版本，旧稿与文件继续保留。当前每项目最多 3000 条记录，达到限制时提示导出保留，不静默裁掉历史。

## 各类型闭环

| 类型 | 连续创作行为 | 交付与边界 |
| --- | --- | --- |
| 小说 | 内容与美术→对象文字与图像→选择确认对象→正文→从正文提取人物／背景更新建议，逐项采用 | TXT / Markdown 短篇；使用确认的对象文字，未记录的图像细节不自动推断；长篇编排未实现 |
| 视频 | 脚本与概念对象→可视参考画廊→可选多图首帧准备→候选采用→将该实际图片作为单镜头起始画面 | MP4 与原声音／合成工具；无需先生成分镜；概念图更新不会悄悄替换镜头选定图片 |
| 网站 | 当前需求／美术／素材→任务包→执行端完成任意合适技术的源码→ZIP 候选→采用→下一轮任务实际携带该源码 | 源码 ZIP、运行与验证说明；不套固定模板，不在 Runtime 执行任意构建命令；静态 HTML 可隔离预览 |
| 3D 文创 | 形体／文化依据／使用展示→概念对象与实际图像→设计资料包→继续完善 | 含 DESIGN.json、来源和实际图片的 ZIP；为后续 3D 制作提供资料，没有模型、拓扑或纹理生成 |
| 暂未确定 | 内容、对象和视觉成果持续保存→跨媒介资料包→确定类型后显式沿用 | 可交付资料 ZIP，不虚构已完成的媒介成品 |

图像适配器首帧准备提供 1:1、3:2、2:3；视频仍用 16:9 / 9:16，不为匹配画幅静默裁切参考图。多图实际效果依赖真实图像服务。

## 类型分支与旧数据

原始想法、文化背景、按类型存储的内容和素材库保留在项目层；创意方案、美术、参考用途、概念对象、阶段要求和成品按作品类型保留分支。切换类型不复制另一类型的美术或对象。用户可明确沿用原创意、美术、指定概念对象，并将原内容作为适配资料；不直接覆盖当前类型小节。再次切回恢复该类型草稿。原版本的专属小说／视频／网站成果按所属类型读取，旧文件继续保留。

## Runtime、MCP 与 Skills

核心协议为 4，共 19 项工具。新增：

| 工具 | 操作 |
| --- | --- |
| workflow_get | 只读返回输入清单、相关变化和历史版本 |
| workflow_update | inherit / restore / adopt-website-source，版本检查与幂等写入 |
| website_source_import | 从当前项目 inbox 导入真实源码 ZIP 为候选；可关联原网站任务与来源 |

`task_start` 新增 `video-frame` 和 `design-package`；`task_adopt` 支持 `objectIds` / `sectionKeys` 选择采用。对象和镜头字段见 Skills 的 `references/continuous-workflow.md`。两项 Skills 为 0.3.0，setup 同时打包共用文化规则和连续创作说明，连接本身仍由用户手动加载验证。

Web 上传源码使用 `POST /v1/files/website-source`；只检查并保存候选元数据。ZIP 最大 128 MB，单文件 32 MB，解包后合计 128 MB，最多 5000 项；拒绝穿越路径、重复名称和只有提示词而没有代码的包。读取 ZIP 不向磁盘解包或执行代码。静态预览使用单独只读路径和 sandbox CSP，禁止网络连接、表单和页面嵌套；后端、依赖安装与构建检查由执行端承担。导入文件的声明与执行端检查记录不等于工作台验证功能通过。

真实服务、WorkBuddy 实际加载和作品质量仍单独验收。本地自动检查与隔离操作证据见 [本轮验收记录](WORKFLOW_VERIFICATION_20260908.md)。
