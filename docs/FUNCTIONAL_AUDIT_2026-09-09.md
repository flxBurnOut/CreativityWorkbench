## 已修复

| 问题 | 处理 | 验证 |
| --- | --- | --- |
| WorkBuddy 保存后网页仍显示旧项目或旧稿 | 空闲时每 5 秒读取共享工作区，返回页面时也同步，保留本机正在编辑的稿件 | 隔离 Runtime + 浏览器：对话接口新建、修改后，网页无需刷新即出现 |
| 两端同时修改后一直保存失败 | 基于上次确认版本重整；不同项目合并，同一项目冲突保留远端并产生本机副本；失败仍保留待保存稿 | 4 项纯逻辑测试；浏览器同时改稿确实出现“本机冲突副本”，两份内容保留 |
| MCP 已采用的任务仍提示待采用 | 采用写入成功后收起候选，幂等重放补齐收起 | 核心接口回归；网页生成→预览→采用后候选收起 |
| 另一作品类型的未完成图像阻塞当前类型 | 任务占位加入作品类型，排队时记录类型 | 同类型重复仍拒绝，不同类型允许 |
| 网站任务包读回后不能再次保存编辑 | 严格输入契约接受已保存的 ZIP、来源和任务字段 | 实际生成任务 ZIP 后读回、修改、保存 |
| 未选择对象仍可点击采用 | 空选择禁用采用入口，后端继续拒绝无效选择 | 输入校验保留 |
| 停止任务时仍可能有后台写入 | 停止排队计时器、取消处理并提供可等待的收尾 | 提示词回归测试不再与临时目录清理竞态 |

## 能力核查范围

- 保存、类型分支、采用、版本检查、恢复和文件备份：本地接口/回归覆盖；同步与并发另经浏览器操作。
- 创意、内容、美术、短篇：实际请求、候选、采用流程使用固定模拟响应验证；未配置真实文字服务，不代表真实模型质量通过。
- 图片生成/改图：真实图片文件解码、原图传递和 WorkBuddy 文件交接经本地模拟回归；真实供应商待验证。
- 单镜头、旁白、字幕与合成：测试使用实际本地媒体和 FFmpeg；供应商请求用模拟服务。真实视频生成待验证。
- 网站：提示词与素材包、源码 ZIP 候选导入、采用、受限静态预览、下一轮真实源码交接有本地测试。任务包不是生成完成的网站。
- WorkBuddy：实际 stdio MCP 客户端协议测试包含读写、媒体交接与交付；WorkBuddy 应用内的 Skills/MCP 加载和真实能力仍由用户手动测试。
- 3D：仅前期资料和概念参考，未实现模型、拓扑或材质生产。
