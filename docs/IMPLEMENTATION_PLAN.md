# 实施计划

更新日期：2026-09-08。

本轮补充：核心 Skills／MCP 封装已实现（2 项 Skills、12 个工具、共享 Runtime 与本机连接配置），覆盖既有核心流程。仅完成本地协议与文件处理验证，WorkBuddy 实际装载、技能触发和真实服务生成由用户随后测试。步骤见 [WORKBUDDY_CORE.md](WORKBUDDY_CORE.md)。

用户确定按原顺序完成 1、2、3；图像以 WorkBuddy 为优先，同时保留外部 API。文创成品确定为 3D 资产，排在最后。近期保留 B＋C 岭南主题和五阶段流程。

| 顺序 | 范围 | 当前状态 |
| --- | --- | --- |
| 1 / M0 | 服务端项目、文件保存、任务状态、草稿迁移与备份 | 已实现，本地验证 |
| 2 / M1 | 创意、内容、美术提示词、自然语言修改、完整短篇与下载 | 接口和页面已接线；真实模型质量待验 |
| 3 / M2 | 概念图、封面、带原图返工、选定参考集 | WorkBuddy 消息和文件交接、外部 Images API 已实现；真实账号和出图待验 |
| 4 / M3 | 视频镜头、必要声音／字幕、合成、播放与下载 | 已实现；本地处理与模拟接线通过，真实服务待验 |
| 5 / M4 | 网站页面、约定交互、隔离预览、源码和运行说明 | 已实现；本地模拟通过，真实模型质量待验 |
| 6 / M5 | 3D 文创资产，模型细节、文化准确性、拓扑和实际导出 | 最后实施，当前暂缓 |

文化来源整理、《织梦者》素材复用、至少一个真实非游戏 Demo 和比赛交接贯穿上述过程。消息接入不代表完整 WorkBuddy 工作台装载已验证；比赛要求仍须逐项实测。

详见[多媒体生成器计划](design/MULTIMEDIA_GENERATION_PLAN.md)及[当前功能与配置](MULTIMEDIA_RUNTIME.md)。旧 [3D 提案](design/COMPETITION_3D_REVISION.md)保留为历史参考。能力清单登记实际接口，并单列本地模拟与真实服务验证状态。执行 npm test、npm run lint、npm run typecheck、npm run build；不以模拟结果代替真实成品。
