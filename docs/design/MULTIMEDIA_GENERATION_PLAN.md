# 多媒体生成器实施计划

更新日期：2026-09-08。用户确定：先按原顺序完成保存与任务、文字、图像；随后视频、网站；文创成品只做 3D 资产，放到最后。沿用岭南文化、B＋C 界面和五阶段操作。3D 模型细节与拓扑未解决前，不用概念图冒充数字资产。

## 当前范围与完成标准

前 1、2、3 项已完成本地实现与模拟接线，真实服务联通和作品质量仍未验收。详细边界与配置见[运行说明](../MULTIMEDIA_RUNTIME.md)。每种媒体都须经历明确输入、真实请求、可恢复状态、有效文件、用户预览采用、修改与下载；按钮存在和示例可见不能替代实测。

- 保留用户当前原文、文化依据和生成来源，不编造历史来源；未知事实标为待核实。
- 请求采用固定输入快照，迟到结果不覆盖后续编辑；未采用结果仍可复制或下载。
- 刷新和普通查询不重复发起付费请求；状态不明时不自动重发。
- 结果文件可解码，修改前保留旧稿；配置、模拟、真实联通、质量验收分别记录。

## 1 / M0：保存与任务

已实现服务端项目快照、受控 PNG、请求和结果记录、查询、取消等待、旧草稿迁移及 JSON 项目备份。写入串行且校验版本；支持旧输入保护、请求去重、重启后恢复／标为待核实。移除引用暂不删除磁盘文件，后续另做垃圾回收。

验收：重启恢复项目；重复提交只执行一次；保存冲突不覆盖；失败保留原稿；旧浏览器数据保留原副本。当前单 Runtime 写目录；不宣称多人同步编辑或断电级事务保障。

## 2 / M1：文字工作流

已实现创意完善／换方向／修改、按作品类型生成内容方案、整篇／指定小节／选区修改、遗漏检查、美术提示词整理／修改、对象清单提取、完整短篇正文与 TXT／Markdown 下载。正文与标题可手动编辑；采用结果后保存，可短暂撤销。

文字通过 DeepSeek V4 Flash。参考图片用途可作为文字约束，但未接视觉理解，不声称模型已看图。对象提取不会自动生图。小说当前支持一篇有结尾的短篇；长篇所需章节队列、设定约束和上下文管理待实现，不能承诺任意长度一次生成。

真实验收：用《织梦者》自有资料检查文化准确性、修改遵循度，以及完整短篇的正文与下载一致；美术文字阶段不发起生图请求。

## 3 / M2：图像生成、原图返工与参考集

优先通过 WorkBuddy 官方消息接口发送请求，工作台准备本机文件并回收实际 PNG；没有自动发送授权时提供明确的手动复制请求入口。同时保留可配置地址／密钥／模型的外部 Images API。

生成包含文化语境、美术规则、当前对象和至多四张实际美术参考。返工必须传原图，默认沿用原图保存的风格并带入修改项，生成新候选时保留旧选定图。结果预览、实际提示词、下载、候选采用、选定参考和封面引用可追溯。

真实验收：WorkBuddy 完成一次生成、一次针对原图的编辑，并正确写回；页面保存参考、刷新恢复、删除和撤销一致。外部 API 单独验证相同链路。接口模拟通过不代表 WorkBuddy 账号已具有可调用的生图能力。

## 4 / M3：视频成品（已实现，本地与模拟验证）

本轮实现与边界见[视频与网站交付](../VIDEO_WEBSITE_RUNTIME.md)：可编辑分镜、WorkBuddy 视频与配音交接、Runway Gen-4.5 异步任务、真实媒体导入、字幕／配音／配乐和 FFmpeg 合成。真实供应商验证仍未完成。

原验收目标：从脚本生成必要镜头、时长、画幅、人物与视觉保持项及声音要求。先验证一个真实镜头的提交、状态查询、保存与播放，再完成多镜头作品；失败或修改只重做相关镜头。必要旁白、字幕、配乐按实际服务与素材来源处理，合成为可播放和下载的真实视频。音频服务支撑视频，不扩展独立音乐工作台。

单镜头成功仅算接口验证；完整必要镜头、声音要求和自动合成都满足后才算成品完成。不预先承诺任意时长或角色绝对一致。

## 5 / M4：网站成品（已实现，本地与模拟验证）

已实现受控 JSON 网站生成与本地编译、1–5 页面导航、图库搜索筛选、FAQ、隔离预览、手动和 AI 修改、离线源码包。真实模型质量仍待验。

原验收目标：从内容、页面结构、视觉规则及选定素材生成实际文化展示页或轻交互专题页。页面在隔离环境预览，不能直接执行生成代码或接触服务端密钥。导航、移动布局、按钮行为、资源引用逐项验证；登录、支付、数据库等未实现能力不列入交付。

交付源码、素材、依赖与启动说明，并在独立环境打开；静态截图和无行为按钮不算可运行网站。

## 6 / M5：3D 文创资产（最后实施）

文创明确为 3D 资产，不改成海报或明信片。待前述模块稳定后，另行落定三维编辑方式、资产来源、实际格式及验收样例。重点验证文化细节、形体结构、拓扑、材质和可编辑性；支持范围由工具实测决定。当前只可整理内容需求和概念参考，模型生成、编辑、拓扑处理、文化空间及三维导出全部暂缓。

验收须包含实际模型文件、可检查细节及拓扑的视图、一次有针对性的编辑与重新导出；渲染图片不能替代资产文件。

## 贯穿任务：复用与比赛交接

整理《织梦者》自有文化资料与资产来源，新资料和生成结果单独标注；复用同一内容制作至少一个可独立体验的非游戏 Demo。文化资料和 WorkBuddy 装载方式从第一步核实，不能把本轮官方消息接口接通视为比赛装载要求已满足。

首类成品稳定后再验证第二媒介，回应不同媒介的实际使用方式。由非作者按文档启动、配置、创作、修改与下载，并与生产工作台共同准备沉淀说明、Demo、视频和路演材料。完整路线不等于比赛截止前全部完成的承诺。
