## 布局检查

已在 1440、1024、768、390、360 像素视口下检查首页及代表性阶段，未发现页面横向溢出。360 像素下检查了长项目名称、五阶段导航、网站预览和帮助弹窗。

使用临时 CSS `zoom: 2` 检查 200% 放大时的首页、编辑页及改名弹窗，未出现页面横向溢出，输入焦点与关闭操作可用；验证后已移除临时样式。该检查为布局放大检查，不等同于全部浏览器原生缩放模式的兼容性认证。

已目视检查场景、概念图与表单；图片保留原色，编辑面保持浅色实底。正常辅助字号统一以 12px 为基线，主题中偏浅的文字颜色已加深。减少动态偏好有对应 CSS。完整屏幕阅读器审计、逐状态对比度测量与多浏览器兼容性仍需在正式上线前补充。
