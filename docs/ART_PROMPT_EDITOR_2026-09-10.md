# 美术提示词编辑器 · 2026-09-10

美术模块只负责编写一段后续出图使用的提示词。页面主编辑框是当前生效稿，可直接编辑、粘贴、复制，修改自动保存；AI 起草或按本轮要求修改，结果作为候选展示，与当前稿对照后点击“替换为此提示词”。采用后停留本步，用户自行进入准备图片。

## 数据与兼容

- `art.fullPrompt` 为统一生效文字。旧项目的 `direction/material/palette/constraints` 和旧综合描述全部合并显示，保留标签与原文；不静默决定冲突项的优先级。编辑或采用新稿后将旧分项置空。原结构留在历史中，类型分支、保存重开与恢复继续有效。
- `project_update.patch.art={fullPrompt:"完整提示词"}` 原子替换并清空旧分项。旧客户端的分项写入仍可接受，合并为同一段可见文字；现有版本检查和幂等回执保留。
- 新 `art` 任务通过 `args.instruction` 固定本轮要求。编辑下一轮要求不会令本候选过期；改动当前稿、内容或文化依据仍会阻止覆盖。兼容旧任务的来源快照与旧结构结果。
- 文字服务只需返回 `{fullPrompt:"完整提示词"}`，经验证后规范化保存。生成结果不会自动采用。此阶段未附图片，不声称文字服务看过参考图。
- 风格参考图移动到“准备图片”的可选区域。现有文件、用途说明、移除与撤销继续保留，随真实出图请求发送。新概念图、封面、视频首帧、自动准备的视频和网站提示词使用同一当前画风。已有图片局部编辑默认保持原风格，明确选择换风格时才使用当前稿；已保存的视频/网站编辑提示词仍需按既有依据检查规则重新核对。

核心协议 **14**、**31 个工具**，Skills **0.11.0**。共用文化规则除美术字段优先级改为当前提示词外保持原约束。运行 `npm run workbench:setup` 已生成更新的本机导入包，未自动向 WorkBuddy 发送消息或重新安装。
