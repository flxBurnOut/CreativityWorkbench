# 岭南行笺

具体的文创文旅非游戏 Demo，不是工作台内置网站生成模板。完整交付包由 `npm run demo:tourism` 在 `work/deliverables` 中生成；该命令在独立目录创建演示项目，保存原创短篇、选择主题视觉资产，再实际沿用到网站并导出交接包。不调用付费模型，不触碰用户项目。

解压成品 ZIP 后打开 index.html 即可浏览，也可导入工作台作为网站源码候选。网站提供文化分类、文字搜索、插画预览、知识出处、原创故事、探索清单与下载、反复开合 FAQ；无预约、票务、支付、地图或营业信息接口。隔离预览下本地收藏可能不可持久保存，页面会提示。

文化资料和素材来自工作台版本化知识与原创视觉库。插画不是实景照片、文物复刻或传统工艺实物；具体故事为虚构。事实与原站媒体权利分别记录。原始 SVG 与文化、跨媒介来源记录在包内保留。

此示例只证明当前工作台的知识和资产向网站交付的复用链路。WorkBuddy 的实际 Skill/MCP 加载与使用仍应在用户客户端单独复测。
